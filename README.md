## 📚 Conteúdos praticados

### 🔀 Branches

Criação e gerenciamento de branches para trabalhar com diferentes versões e funcionalidades sem comprometer a branch principal.

```bash
git branch
git branch nome-da-branch
git switch nome-da-branch
```

### 💾 Commits

Prática de criação de commits organizados e descritivos, mantendo um histórico que facilite o acompanhamento das alterações.

```bash
git add .
git commit -m "mensagem do commit"
```

### 🔄 Merge

Integração das alterações de uma branch em outra.

```bash
git merge nome-da-branch
```

### ♻️ Rebase

Estudo do `rebase` para reorganização do histórico e integração de alterações entre branches.

```bash
git rebase nome-da-branch
```

### 🧳 Git Stash

Utilização do `stash` para armazenar temporariamente alterações que ainda não devem fazer parte de um commit.

```bash
git stash
git stash list
git stash pop
```

### 🪝 Git Hooks

Estudo dos **Git Hooks**, que permitem executar scripts automaticamente em determinados momentos do fluxo do Git, como antes de um commit ou push.

Entre os conceitos estudados:

* `pre-commit`
* `commit-msg`
* `pre-push`
* validações automáticas
* execução de testes
* padronização de código

Hooks podem ser utilizados para automatizar verificações e ajudar a manter padrões de qualidade durante o desenvolvimento.
